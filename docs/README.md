# OS2fri Dokumentation

Velkommen til dokumentationsarkivet for **OS2fri**.

Dette bibliotek indeholder fælles arkitekturbeskrivelser, behovsafdækninger og teknologivalg for flådestyring og digitale arbejdspladser i OS2-fællesskabet.

## Formål
Mappen samler det åbne grundlag for projektet, så myndigheder og bidragere har fuld transparens og indsigt i løsningens principper.

## Bidrag
Bidrag og nye dokumenter er meget velkomne. For at sikre sporbarhed bedes større ændringer og tilføjelser forankret i et åbent issue på repository'et, og pull requests holdes afgrænset til det aktuelle emne.
